# Move The Gauntlet (Roblox) to another computer
1. Unzip. Put `The-Gauntlet-Roblox/` anywhere (e.g. Documents\Roblox\).
2. Install Rokit (rokit.toml pins Rojo 7.7.1): https://github.com/rojo-rbx/rokit  then in the folder run `rokit install`.
3. `rojo serve` in the folder; in Roblox Studio open a Baseplate, Plugins > Rojo > Connect.
4. Saving needs: Game Settings > Security > "Enable Studio Access to API Services" + a published place.
5. Read PORT_STATE.md (what is built / not) and project-docs/ (plan + roadmap).
Optional checks: luau tests are in tests/ (need a Luau CLI).
